# 4x1000.co

Calculadora del 4x1000 (GMF) de Colombia, con guías y páginas por monto. Astro estático con
calculadoras en Svelte 5 y Tailwind. Se despliega en Vercel desde `main`.

```bash
npm install
npm run dev      # desarrollo
npm run build    # genera dist/
npm test         # cuentas del GMF
```

Las cifras del año (UVT, topes, salario mínimo, fuentes) viven en `src/data/tax.js`.
Requiere Node 22.23.4 o superior.
